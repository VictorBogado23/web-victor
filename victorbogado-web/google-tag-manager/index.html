¿Qué es Google Tag Manager y para qué sirve?

Google Tag Manager (GTM) permite gestionar las etiquetas que envían información de tu sitio a herramientas como Google Ads, Meta Ads y Google Analytics. Una etiqueta envía los datos, un activador define cuándo hacerlo y las variables aportan información sobre la acción. Instalar GTM no significa que tus conversiones estén bien medidas.

¿Estás midiendo conversiones o simplemente interacciones?

Si gestionás campañas o invertís en publicidad, es importante distinguir una intención de un resultado confirmado. Estas señales no tienen el mismo valor.

INTERACCIÓN

Clic en enviar formulario

El usuario puede hacer clic sin completar los campos o recibir un error. No confirma una consulta.

SEÑAL INDIRECTA

Página de agradecimiento

Puede funcionar si el acceso está controlado, pero una recarga o visita directa podría generar duplicados.

RESULTADO CONFIRMADO

Evento de formulario enviado

Se registra cuando el sistema confirma que recibió la consulta, no simplemente cuando alguien hace clic.

DATOS DE MAYOR CALIDAD

Conversión enriquecida

Incorpora los datos permitidos para mejorar la coincidencia y atribución en las plataformas publicitarias.

Cómo configurar conversiones con eventos en Google Tag Manager

La capa de datos (data layer) permite comunicar a GTM qué ocurrió realmente en el sitio. Por ejemplo, cuando un formulario se envía correctamente, se puede emitir un evento que active las etiquetas correspondientes.

  1. Acción del usuarioCompleta el formulario.
  2. Confirmación del sistemaLa consulta se recibe correctamente.
  3. Evento en GTMSe activa la etiqueta con los datos permitidos.
  4. Plataformas publicitariasGoogle Ads y Meta Ads reciben la señal.

En ecommerce, la compra debe registrarse al confirmarse el pedido, con su identificador, valor y moneda. Un clic en WhatsApp indica intención de contacto, pero no confirma que exista una conversación. Cuando es posible, conviene conectar el CRM o sistema comercial para medir leads reales y ventas.

Conversiones mejoradas de Google Ads y datos enriquecidos en Meta Ads

Cuando una persona completa un formulario o realiza una compra, determinados datos propios, como el correo electrónico o el teléfono, pueden ayudar a relacionar esa acción con las interacciones publicitarias. Google Ads utiliza conversiones mejoradas; Meta ofrece coincidencia avanzada y API de Conversiones.

Estos mecanismos pueden mejorar la atribución, pero requieren una implementación que respete las políticas de cada plataforma, el consentimiento aplicable y los requisitos de seguridad y hash. No se deben enviar datos personales identificables como parámetros ordinarios de GA4.

¿Qué conversiones deberías medir?

Generación de leads

Formularios recibidos, reservas confirmadas, leads calificados y ventas cuando el sistema comercial lo permite.

Ecommerce

Compras confirmadas con valor, moneda e identificador de transacción. Los carritos y el inicio de pago pueden servir como señales secundarias.

En Google Ads, elegí como conversiones principales las acciones que correspondan al objetivo de optimización. No todas las interacciones deben alimentar las pujas automáticas.

Preguntas frecuentes

Preguntas frecuentes

¿Trabajás sobre mi contenedor o creás uno nuevo?

Depende de cómo esté. Si el contenedor se puede ordenar, trabajo sobre el existente. Si está muy desordenado, a veces conviene uno nuevo y migrar lo que sirve. Te lo digo en la auditoría.

¿Necesito Consent Mode si vendo sólo en Argentina?

Depende de los usuarios, las plataformas y las normas aplicables. Reviso los requisitos de consentimiento de tu implementación y cómo se transmiten las preferencias a las etiquetas.

¿Qué necesito darte para empezar?

Acceso de edición a tu contenedor de Tag Manager y acceso de lectura a GA4 y Google Ads. Nada más para la auditoría.

¿Me dejás documentado el contenedor?

Sí. Cada implementación termina con una documentación de etiquetas, activadores y variables, para que cualquier persona pueda entender qué hace cada cosa.
